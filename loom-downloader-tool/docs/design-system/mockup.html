Sifão Baixador de aulas — Skool · Loom · YouTube · Vimeo
proposta de identidade · v3

Uma extensão, uma linguagem visual só. O mesmo pill sobre qualquer vídeo; toda a inteligência de curso e status no popup.

Nome “Sifão” é sugestão — troque à vontade (ideias: Cascata, Colheita, CourseGrab). O que importa aqui é o sistema visual, o ícone e onde cada ação vive. Alterne o tema (☀/🌙) no topo da página para ver claro e escuro.

01 · Paleta & tokens

Azul-elétrico com um aqua de apoio — nada de verde-Skool nem vermelho-YouTube

Identidade própria e neutra entre as plataformas. Cores semânticas (online/erro) são separadas do acento, para estado nunca competir com marca.

Contextual à aba

O popup lê a aba ativa: se for uma classroom do Skool, mostra o curso e o botão “Baixar curso inteiro”. Fora do Skool, esse bloco some.

Status real do servidor

O pontinho verde/vermelho faz ping no localhost:5000. Você sabe na hora se precisa subir o servidor — sem clicar e ver “offline”.

Página limpa

Sai o botão flutuante de curso no canto. A página do Skool volta a ser a página do Skool; a ação de lote mora no popup.

06 · Antes → depois

De cinco superfícies soltas a um sistema

ANTES — bagunça
  • Verde #00d084 numa tela, roxo #6c5ce7 na outra
  • 4 posições diferentes (sobre o vídeo, 2× canto inferior, flutuante)
  • 3 textos p/ “baixar vídeo”, sem ícone de marca
  • Botão de curso flutuando “tipo anúncio”
DEPOIS — Sifão
  • Um acento, um gradiente, um mark em tudo
  • Pill sempre no canto do vídeo; lote e status no popup
  • Ícone de toolbar próprio (16→128)
  • Página limpa, cara de produto para o GitHub
